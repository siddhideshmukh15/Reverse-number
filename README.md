# Reverse Number
A simple **Reverse Number** project built using Python. This beginner-friendly project takes a number from the user and reverses its digits.

## Features

- Accepts a number from the user
- Reverses the entered number
- Displays the original number
- Displays the reversed number
- Displays the number of digits
- Simple and beginner-friendly

## Technologies Used

- Python
- Strings
- String slicing
- `len()`
- User input
- Variables

## Concepts Learned

- Taking user input
- Working with strings
- String slicing
- Using `len()`
- Variables
- Basic string manipulation

## Future Improvements

- Reverse numbers using a loop
- Check whether a number is a palindrome
- Handle negative numbers
- Add input validation
- Reverse multiple numbers
